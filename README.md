# Ask Your Screen

A one-page comparison of tools that record your screen locally and let you ask questions about it later: **Screenpipe**, **LUCI** and **Microsoft Recall**. Includes setup guides, a side-by-side table, an FAQ and a pilot plan.

Open `index.html` in a browser, or view it on GitHub Pages.

Researched 30 Sep 2026. Prices and features change, so check each vendor's site before buying.
